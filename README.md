# Ghostty is not a Wawona product

This checkout is not a Wawona input. Do not port libghostty into Wawona,
and do not add a `wwn-ghostty` flake input.

Toolbar keys live in `github.com/Wawona/ToolbarKeys`. Phone client tabs
live in Wawona. Both start from the Rootshell idea. The terminal grid
does not.
